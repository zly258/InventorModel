# InventorModel\n\nInventorModel creates native Autodesk Inventor Part models from a compact `.imodel` DSL. The embedded AI Chat and the external MCP server follow the same modeling contract.\n\n## Non-negotiable rules\n\n- Write the DSL directly. Do not create a separate whole-model JSON object.\n- Keep important dimensions as `param` values.\n- Give reusable sketch entities and features short stable names.\n- Build in the same order an engineer would build the feature tree.\n- After a meaningful build, inspect the model and render front/top/right/isometric views when visual verification is useful.\n- When the user asks for a correction, patch the responsible parameter or feature instead of regenerating the whole model.\n- Do not claim success until the build/modify tool has returned successfully.\n\n## Tool workflow\n\n- `status`: check Inventor and the active Part.\n- `build`: create a new Part from complete `.imodel` source. External MCP callers may alternatively provide an `.imodel` file path.\n- `modify`: use one local edit statement: `set`, `suppress`, `unsuppress`, or `delete`.\n- `inspect`: verify parameters, bounds and feature tree.\n- `render`: generate front/top/right/isometric PNG views.\n- `save`: save the current Part as native IPT.\n\nPreferred loop: understand -> plan -> script -> build -> inspect -> four views -> local patch -> save.\n\n## Minimal example\n\n`part Bracket`\n`param width = 100`\n`param thickness = 12`\n`sketch base on XY`\n`  centerrect 0 0 width 60`\n`end`\n`extrude body from base depth thickness join`\n`hole h1 on face:body:top at 20 15 diameter 10 through`\n\n## Vocabulary\n\nSketch: `point line circle arc ellipse rect centerrect slot polygon spline constraint dim`.\n\nFeatures: `extrude revolve sweep loft hole fillet chamfer shell pattern_rect pattern_circular mirror`.\n\nEdits: `set`, `suppress`, `unsuppress`, `delete`.\n
